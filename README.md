# Black Oak Society

> **Crafted for the Extraordinary.**

Black Oak Society is a full-stack MERN e-commerce application built as
my flagship portfolio project. The goal of this project is to
demonstrate practical full-stack development skills by implementing
authentication, product management, shopping workflow, payment
integration, image management, and a responsive user experience.

> **Status:** Active Development

------------------------------------------------------------------------

# Live Demo

**Frontend:** https://black-oak-society.vercel.app

# Tech Stack

## Frontend

-   React
-   Vite
-   React Router
-   Tailwind CSS
-   Axios
-   Lucide React
-   Swiper.js
-   GSAP (where implemented)

## Backend

-   Node.js
-   Express.js
-   MongoDB
-   Mongoose

## Authentication

-   JWT Access Token
-   JWT Refresh Token
-   HTTP Only Cookies
-   Role Based Access Control (RBAC)

## Storage

-   Cloudinary

## Payments

-   Razorpay

## Deployment

-   Frontend: Vercel
-   Backend: Render
-   Database: MongoDB Atlas

# Getting Started

## Clone Repository

``` bash
git clone https://github.com/ayushray198-coder/Black-Oak-Society.git
cd Black-Oak-Society
```

## Backend

``` bash
cd backend
npm install
npm run dev
```

## Frontend

``` bash
cd frontend
npm install
npm run dev
```

------------------------------------------------------------------------

# Environment Variables

Create `.env` files for both frontend and backend.

> Configure values such as MongoDB connection, JWT secrets, Cloudinary
> credentials, Razorpay keys, email configuration, and frontend/backend
> URLs according to your local or production environment.
